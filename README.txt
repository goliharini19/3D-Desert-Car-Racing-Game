DESERT RALLY - UNITY 3D CAR RACING GAME
Unity Editor version: 6000.6.0f1

OPENING THE PROJECT
1. Extract the ZIP file.
2. Open Unity Hub -> Projects -> Add -> Add project from disk.
3. Select the extracted folder named DesertRacer_Unity (the folder containing Assets, ProjectSettings and Packages).
4. Open it with Unity 6000.6.0f1.
5. Wait for scripts to compile. The Editor setup script automatically creates Assets/Scenes/DesertRally.unity and adds it to Build Settings.
6. Open Assets/Scenes/DesertRally.unity if it is not already open, then press Play.

CONTROLS
W / Up Arrow: accelerate
S / Down Arrow: brake / reverse
A / Left Arrow: steer left
D / Right Arrow: steer right

GAME FEATURES
- Procedurally generated desert race environment, sand dunes, rocks, cactus and dry bushes
- Asphalt road, dashed center line, edge markings and start/finish gantry
- Player car and five rival cars
- Countdown, speed HUD, lap counter and race timer
- Third-person follow camera

NOTE
This project uses built-in Unity primitives and scripts, so it does not require downloading external assets or installing packages. Scene generation runs automatically when the project is first opened in the Unity Editor. The game is a playable starter project; you can customize models, textures, audio and advanced racing physics later.
