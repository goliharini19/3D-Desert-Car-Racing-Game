
# 🏜️ 3D Desert Car Racing Game

A 3D desert-themed car racing game developed using **Unity 6 and C#** as an academic project at SR University.

## 📌 Project Overview

The 3D Desert Car Racing Game provides an interactive racing experience in a desert environment. Players can select their preferred car, compete against computer-controlled opponents, complete multiple laps and reach the finish line.

## 🎮 Features

- Desert-themed 3D racing environment
- Four car selection options
- Player-controlled racing car
- Computer-controlled opponent cars
- Multiple laps and checkpoints
- Nitro boost functionality
- Speed, time and score display
- Pause and resume functionality
- Race results and leaderboard
- Restart and main menu options

## 🛠️ Technologies Used

- Unity 6 (6000.6.0f1)
- C#
- Unity GameObjects
- Unity UI (UGUI)
- Visual Studio Code

## 🎮 Game Controls

| Key | Action |
|---|---|
| W / Up Arrow | Accelerate |
| S / Down Arrow | Brake / Reverse |
| A / Left Arrow | Steer Left |
| D / Right Arrow | Steer Right |
| Shift + W | Nitro Boost |

## 📂 Project Structure

- `Assets/` – Game scripts and project assets
- `Packages/` – Unity package dependencies
- `ProjectSettings/` – Unity project configuration

## 💻 How to Run the Project

1. Download or clone this repository.
2. Open Unity Hub.
3. Select Add Project from Disk.
4. Choose the downloaded project folder.
5. Open it using Unity 6 (6000.6.0f1).
6. Open the DesertRally scene.
7. Press the Play button to start the game.
